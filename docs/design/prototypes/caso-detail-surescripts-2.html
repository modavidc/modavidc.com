El contexto

MediRec ya contaba con integración ePrescribing en abcEHR, pero la evolución de los estándares regulatorios de Surescripts y NCPDP requería una recertificación completa de la plataforma.

La actualización implicaba adaptar la integración existente hacia nuevas versiones del estándar clínico, mantener compatibilidad operativa y garantizar continuidad sobre workflows reales de prescripción electrónica.

El objetivo era conservar conectividad con la red nacional de farmacias de Estados Unidos sin interrumpir la operación clínica.

El desafío

La migración involucraba múltiples capas técnicas y regulatorias:

  • actualización de transacciones NCPDP SCRIPT,
  • adaptación de XMLs clínicos y estructuras legacy,
  • nueva API de integración desarrollada desde cero,
  • compatibilidad entre sistema desktop .NET y nueva API Laravel,
  • mTLS y certificados X.509,
  • TLS 1.2+ y hardening de conectividad,
  • validación individual de transacciones clínicas,
  • testing coordinado con Surescripts,
  • y recertificación completa post-migración NLM.

Además, gran parte del proceso dependía de documentación fragmentada, validaciones manuales y troubleshooting coordinado directamente con el equipo de integración de Surescripts.

Mi rol

Lideré técnicamente la migración y recertificación de la integración ePrescribing.

El trabajo incluyó:

  • diseño e implementación de una nueva API en Laravel para integración Surescripts,
  • adaptación de workflows clínicos existentes,
  • actualización de XMLs y transacciones regulatorias,
  • integración entre backend Laravel y aplicación desktop .NET utilizada por médicos,
  • implementación de conectividad segura vía mTLS,
  • troubleshooting regulatorio,
  • coordinación de pruebas de certificación,
  • y soporte técnico durante el proceso completo de validación oficial.

También trabajé directamente con los integration resources asignados por Surescripts durante el ciclo completo de certificación y recertificación.

Contexto

MediRec construyó abcEHR con módulo de ePrescribing. Para que los médicos enviaran recetas a +260K farmacias USA, el sistema necesitaba certificación Surescripts, estándar regulatorio del mercado. Integración compleja con requisitos de seguridad, conectividad y validación clínica.

El problema

Surescripts es ecosystem complejo con documentación fragmentada. Requisitos de seguridad (mTLS, certificados, TLS 1.2+), IP estática, FQDN específica, validación de 7 tipos de transacciones, compliance NCPDP 2017071. Timeline: 3+ años (abril 2020 a octubre 2023).

Mi criterio

Integración regulatoria requiere seguir el proceso exacto de Surescripts, sin shortcuts. Trabajé con integration resource dedicada (Rebecca Bell, luego Tara Collyard). Fases: onboarding, desarrollo de conectividad (mTLS, CSR, ciphers), testing exhaustivo de 7 transacciones (NewRx, RxRenewal, RxChange, CancelRx, Status, Error, Verify), recertificación post-NLM.

La ejecución

Fase 1 (2020): Onboarding, documentación de requisitos. Fase 2 (2020-2021): Desarrollo de API, certificados mTLS, TLS 1.2+ ciphers (ECDHE-RSA-AES256-SHA384, etc). Fase 3 (2021-2022): Testing de 7 transacciones con EHR_INB_Test_Msgs, validación de drug data. Fase 4 (Sept 2023): Recertificación post-migración NLM.

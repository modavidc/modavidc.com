# Habilidades Técnicas

## Full-Stack & Backend

### Node.js
- **Nivel:** Producción (2 años)
- **Contexto:** APIs REST, backends escalables, integración con servicios cloud
- **Casos:** Construcción de APIs completas, optimización de performance

### TypeScript
- **Nivel:** Intermedio-Avanzado
- **Contexto:** Implícito en React y Next.js moderno, type-safety en backends
- **Casos:** Refactoring de código sin IA, mantenibilidad a largo plazo

### AWS Architecture & FinOps
- **Nivel:** Intermedio (Arquitectura + Optimización de costos)
- **Contexto:** EC2, RDS, ALB, Auto Scaling, CloudWatch, Reserved Instances, Savings Plans
- **Casos:** Capacity planning, cost analysis, disaster recovery, load testing validation
- **Gap:** CDK/CloudFormation (learnable, tool-based, no fundamental)

## Frontend & Mobile

### React
- **Nivel:** Producción (2 años)
- **Contexto:** SPAs modernas, component-driven development, state management
- **Casos:** Interfaces interactivas, integración con APIs, optimización de renders

### React Native
- **Nivel:** Producción (2 años)
- **Contexto:** Apps móviles iOS/Android desde código único, navegación, offline-first
- **Casos:** Multipataforma, performance mobile, integración de APIs nativas

### Next.js
- **Nivel:** Producción (1 año)
- **Contexto:** Full-stack React, SSR, API routes, deployment moderno
- **Casos:** Portfolios, aplicaciones isomórficas, adopción de App Router

### Flutter & Dart
- **Nivel:** Intermedio-Avanzado (self-taught, 2+ proyectos en producción)
- **Contexto:** Android/iOS multiplataforma, state management (Riverpod, BLoC), offline-first
- **Casos:** EMR móvil, analytics SaaS, arquitectura de aplicaciones complejas

## Contexto

Con 2+ años en Node.js, 2+ años React, 2+ años React Native, y 1+ año Next.js, tienes los fundamentals sólidos de un full-stack moderno. AWS es arquitectura, no herramienta. CDK es sintaxis.

Un desarrollador que logra:
- **VIPApp:** Flutter + Dart + Backend Node.js en 2 meses sin IA (demonstración de capacidad de aprendizaje)
- **T-Cuida:** Load testing riguroso + FinOps analysis @ 20K usuarios (demostración de pensamiento de arquitecto)
- **Grupero:** SaaS completo con IA integration + freemium (demostración de producto)

...puede aprender cualquier herramienta en 1-2 semanas. El pensamiento es lo que falta en el mercado.

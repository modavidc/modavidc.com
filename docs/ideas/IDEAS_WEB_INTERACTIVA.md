### 21. Football Tactics Board
**Categoría:** Metáfora visual
**Dificultad:** Media

**Cómo se vería:**
Cancha de fútbol interactiva mostrando cómo trabajas en un equipo/organización:

```
                    [Cliente/Usuario]
                          ⚽ GOL
                           │
        [Frontend Dev] ←───┼───→ [Product Owner]
                           │
                     ┌─────┴─────┐
                     │  MOISÉS   │  ← Volante de recuperación
                     │  #6       │     "Recupero datos, distribuyo soluciones"
                     └─────┬─────┘
                           │
           ┌───────────────┼───────────────┐
           │               │               │
      [Base de      [APIs Legacy]    [Servicios
       Datos]                         Cloud]
```

**Interacciones:**
- El balón (dato/request) entra por abajo (sistemas)
- Moisés lo "recupera" (transforma, optimiza)
- Distribuye pases hacia adelante (a devs, productos)
- Ellos meten el gol (entregan valor al usuario)
- Stats en vivo: "Pases completados: 847" "Balones recuperados: 203"

**Animación:**
- Balón moviéndose entre nodos
- Líneas de pase iluminándose
- Cuando hay "gol" (deploy exitoso), celebración sutil

**Frases que aparecen:**
- "No busco el gol, busco el pase que lo habilita"
- "Mi trabajo es que otros brillen"
- "Recupero lo que otros abandonan, distribuyo lo que otros necesitan"

**Tech:** SVG animado + Framer Motion, o Canvas para algo más dinámico

**Por qué es TÚ:**
- Eres integrador, no protagonista
- Conectas sistemas (pases entre jugadores)
- Optimizas flujos (recuperación de balón = limpiar datos/costos)
- Habilitas a otros para anotar (tus clientes, sus usuarios)
- El #6 es el arquitecto del mediocampo, igual que tú arquitectas soluciones
